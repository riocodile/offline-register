# かんたんレジ（オフライン対応）

## 機能
- 商品の追加・編集・削除、価格と在庫管理
- 現金会計、お釣り計算、会計時の在庫自動減算
- 日別・商品別売上集計、取引履歴
- 売上CSV出力、全データJSONバックアップ・復元
- Service Workerによるアプリファイルのキャッシュ
- IndexedDBによる端末内保存

## GitHub Pagesで公開する手順
1. GitHubで新しいリポジトリ（例：`offline-register`）を作成。
2. ZIP内のファイルをすべてリポジトリの最上位にアップロード。`index.html`が最上位にあることを確認。
3. リポジトリの **Settings → Pages** を開く。
4. Sourceを **Deploy from a branch**、Branchを `main`、フォルダーを `/(root)` にして保存。
5. 公開された `https://ユーザー名.github.io/offline-register/` をiPadのSafariで開く。
6. ページが完全に読み込まれたら再読み込みし、数秒待つ。Safariの共有メニューから **ホーム画面に追加**。
7. ホーム画面のアイコンから起動し、商品が表示されることを確認。
8. 初回キャッシュ完了後、機内モードで起動と会計をテストする。

## 重要な注意
- 初回取得とセットアップにはインターネット接続が必要です。以後はアプリファイルがキャッシュされていればオフラインで利用できます。
- iPadOSやSafariのバージョンによってホーム画面アプリの挙動が異なることがあるため、実際に使うiPadで機内モードのテストをしてください。
- 商品・売上データはそのiPadのブラウザ内だけに保存されます。他端末とは同期されません。
- SafariのWebサイトデータ消去、端末故障などでデータを失う可能性があります。営業終了後などにJSONバックアップを保存してください。CSVは表計算用で、復元には使えません。
- 初期状態ではサンプル商品3件が登録されています。販売前に実際の商品に編集してください。
- `index.html`を直接開くローカル確認ではService Workerが動作しません。オフライン機能はHTTPSで公開したURLでテストしてください。
